# Pstock

個人台股投資儀表板。

## GitHub Pages 部署方式
請使用最簡單的分支部署，不使用 GitHub Actions：

1. 進入 **Settings → Pages**
2. **Build and deployment → Source** 選 **Deploy from a branch**
3. **Branch** 選 **main**
4. **Folder** 選 **/(root)**
5. 按 **Save**

部署網址：

**https://peter58501240.github.io/Pstock/**

網站首頁檔 `index.html` 已放在 main 分支根目錄。

## 每日智慧選股（實驗版）

- 網頁：`screener.html`，由首頁「智慧選股」進入；不影響既有持股／損益／圖表。
- GitHub Actions：每日盤後執行 `scripts/run_screener.py`，輸出 `data/screener.json` 至部署網站。
- 股票母體：上市、上櫃四碼普通股；排除 ETF／TDR／金融，且須符合基本量價門檻。
- A：強勢續強；B：止跌轉強；C：潛力觀察。評分僅供排序，不代表勝率或買賣建議。
- 最新日 OHLCV：TWSE STOCK_DAY_ALL（必要時改用 MI_INDEX 日期查詢）＋TPEx 上櫃每日收盤 OpenAPI；歷史日線：Yahoo Finance。
- 歷史資料保留在 GitHub Actions cache，不進版控。第一次執行最多補 650 檔；之後排程會繼續補齊，並在頁面顯示有效覆蓋率。快取失效時可能重新建立。
- 官方行情兩市場不同日期、部分下載失敗、歷史資料未滿 70 根等情況，都會在頁面顯示「資料未齊」，不得當作全市場完整排名。
- 手動更新：GitHub → Actions → Deploy Pstock to GitHub Pages → Run workflow。排程預計台灣時間 14:10 更新、15:35 再檢查資料是否補齊，GitHub 可能延遲。
- 本功能尚未執行嚴謹回測。不得把選股分數、止損參考價當成經過績效驗證的交易系統。

## 交易品質評估 v2（研究版）

- A／B／C 為技術階段；「品質分數」為研究排序，並非勝率、確定買點或交易指令。
- 買點型態：今日收盤確認的 10 日突破、均線區回踩轉強或 B 類止跌轉強；其他列為等待確認。隔日開盤及成交價格尚未知。
- 結構失敗參考線：最近已確認的轉折低點（至少需後續兩根 K 棒確認），若未形成則以先前 10 日低點為候補；在其下方加入 0.25×ATR14 緩衝，同時要求至少 1.2×ATR14 的波動空間，不再直接以 MA10 當作貼近股價的停損線。
- 風險狀態：結構停損相對當日收盤超過 8%、距 MA20 超過 8%／距 MA10 超過 7%，或歷史已確認壓力使預估盈虧比低於 2，均標示「暫不追價」，高技術分不會覆蓋風險警示。
- 盈虧比只在歷史已確認局部高點位於現價上方時估算，不以均線或任意倍數捏造獲利目標；沒有可靠壓力就顯示「未能估算」。
- 另設「原始三條件（獨立）」頁籤：從**全體已完成歷史資料且通過共用初篩（股價≥10 元、量≥700 張、成交值≥2,000 萬元）**的股票中，獨立篩 MACD 柱狀體當天翻正＋布林上下軌向外張開＋股價站上向上的 MA20。這不是原網友 500 張母體的完整重現，兩者請勿混淆。
- 原策略獨立名單與 A／B／C 名單均顯示最多 20／每類 5 檔；資料存取及 GitHub Actions 既有更新機制不變。
- 目前只做盤後訊號與風險診斷，尚未做逐筆進出場回測；隔日實際買價、滑價、除權息及流動性都會影響真正結果。
