# Pstock

個人台股投資儀表板。

## GitHub Pages 部署方式
請使用最簡單的分支部署，不使用 GitHub Actions：

1. 進入 **Settings → Pages**
2. **Build and deployment → Source** 選 **Deploy from a branch**
3. **Branch** 選 **main**
4. **Folder** 選 **/(root)**
5. 按 **Save**

**https://peter58501240.github.io/Pstock/**

網站首頁檔 `index.html` 已放在 main 分支根目錄。
